## Quem cria o repo

O **próprio DEV**, quando for **iniciar** aquela peça (clone do boilerplate / scaffold da extensão).  
Setup **não** cria GitHub; só nomeia e aponta a origem.

## Ordem de nascimento

**Sem ordem fixa.** Cada peça nasce quando o DEV dela começa. Preferência prática (não lei): backend antes se o front/extensão precisar de API — mas não bloqueia gate.
