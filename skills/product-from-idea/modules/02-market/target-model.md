## Mínimos que os modelos reais exigem

1. Definição do mercado (dentro/fora).  
2. Validação com **números nomeados** antes de confiar no SOM.  
3. Funil TAM → SAM → SOM com **conta** e unidade.  
4. Concorrência / alternativas com proposta e falha.  
5. Fonte nomeada (firma de research ou store).  
6. Implicação (seguir / pivotar).  

## Nosso modelo-alvo

1. Dicionário (Mercado total / que faz sentido / pedaço realista)  
2. Definição  
3. Tamanho + **bloco Conta**  
4. Validação / sinais

6. Potencial / captura  
7. Drivers e riscos

10. Confirmado · Hipótese · Aberto · Gate

## Anti-padrões (Mercado)

| Anti-padrão | Sintoma |
|-------------|---------|
| Lista de links | Sem sizing / sem conta |
| TAM theater | Número bonito sem premissa |
| Chute de download | Sem store/browser |
| Só preço | Sem escala / modelo |
| Falha sem voz do cliente | Falhas do concorrente tiradas só do site dele, sem reclamação pública nem fórum |
| Copiar domínio do anexo | “Somos o Airbnb de X” no doc vivo |
| Meta de chat / abreviação | `qtd.`, título de prompt, doc só pro Cursor |
