# Workspace de criação de produto — âncora

> Instalado pela skill `product-from-idea` em {DATA_DO_SYNC}. **Âncora**, não regra: as leis ficam na skill.

Este workspace define um produto **até a tarefa no ClickUp**. Código = **devs**.

## A cada retomada (Controlador)

1. Ler `docs/README.md` — qual fase está aberta.  
2. Reler `{SKILL_DIR}/SKILL.md` e, por ele, `reference/rules.md`, `shared/controller/AGENT.md` e o módulo da fase aberta.  
3. Abrir **um subagente** para a fase aberta (cartão em `{SKILL_DIR}/shared/controller/handoff.md`). O subagente encerra no gate.
