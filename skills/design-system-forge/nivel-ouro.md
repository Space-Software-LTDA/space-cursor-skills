# Níveis de entrega — essencial × ouro

> O Forge entrega o **essencial** por padrão. No STOP, pergunta: **“Quer evoluir para o nível ouro?”**. O ouro só roda com **sim** do humano.  
> Os dois níveis passam pelo GATE ACCEPT e pelo confronto com o [`ui-gosto.md`](../docs/ui-gosto.md). O ouro não afrouxa nenhuma regra do essencial: só acrescenta.

## Essencial (padrão)

| Item | Onde | Critério de pronto |
|------|------|--------------------|
| Diagnóstico tem × falta | Chat + `EXTRACTION_NOTES` | Tabela preenchida com evidência |
| Manual da marca como prancha | Canvas | Essência, cores, tipografia, regras de uso, versões do logo (ou pendência de logo explícita); oficial ou provisório declarado |
| Documento do DS | `.docs/DESIGN_SYSTEM.md` | Template inteiro; fundamentos F1–F8 com computador **e** celular; contraste 4,5:1 e 3:1 |
| Tokens | `.docs/tokens.dtcg.json` | Espelha o documento e as variáveis do canvas |
| Lista fechada de componentes | Documento | Faixa 1 (13 grupos) + Faixa D (domínio) + itens da Faixa 2 com “sim + tela” + proibidos por enquanto |
| Matriz de estados | Documento + bloco no canvas | Nenhuma célula em branco |
| Padrões de tela `P-…` | Documento | Telas do produto + A–D/F |
| Variáveis | Canvas | Valor dark **e** claro; nenhuma peça oficial com cor digitada |
| Prancha Fundamentos (tema principal) | Canvas | Capítulos 01–05; margem e grade computador e celular |
| Prancha Componentes (tema principal) | Canvas | Só a lista fechada, com estados |
| Oficial × Rascunho | Canvas | Separados; nada apagado |
| Confronto com o gosto | `EXTRACTION_NOTES` | Geral + tipo; PASS/FAIL; exceções com OK |

## Ouro (opcional)

| Item | Onde | Critério de pronto |
|------|------|--------------------|
| PDF do manual da marca v1.0 | `.docs/brand/` | Mesmo conteúdo da prancha; sem inventar |
| Segundo tema | Canvas | Fundamentos e Componentes no segundo tema feitos de **instâncias** do principal; contraste conferido; só texto e ícone ajustados (roteiro, passo 24) |
| Faixa 2 completa | Documento + canvas | Todos os itens da Faixa 2 decididos (sim / não) e os “sim” desenhados com estados |
| “Faça / Evite” por componente | Documento + canvas | Cada componente da lista com ao menos um exemplo certo e um errado |
| Capítulos no formato do deck | Canvas | Pranchas organizadas nos capítulos 00–08 do [deck de referência](exemplos/deck-referencia-estrutura.md), com abertura de capítulo e sumário |
| Tela “Tudo junto na prática” | Canvas | Uma tela real do produto montada **só** com tokens e componentes oficiais (capítulo 08). Se revelar falta → volta ao DS com versão |

## Regras

1. Ouro sem essencial PASS = **proibido**.  
2. Ao terminar o ouro: confronto com o gosto sobre o que mudou + novo STOP (mesmo template).  
3. `EXTRACTION_NOTES` registra o nível entregue e a versão do documento.  
4. A tela “Tudo junto na prática” do ouro não substitui a tela-prova e as demais telas do `design-system-apply`.
